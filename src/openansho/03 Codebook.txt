This tutorial is about developing the codebook (especially in collaboration) and navigating your data in OpenAnsho.



First, let's review. Code (this segment) with the code [test1]. Then code (this segment) with [test2]. Finally, code (this segment) with [test]. Note that to make the new [test] code, you will need to navigate through the codebook to the "(add new code)" option; you can do this with the arrow keys, or with the shortcuts ctrl + j/ctrl + k. Remember that once you have text selected, you can press Spacebar to jump to the code entry field, type the new code name, and press Enter to both create and apply the code. This quick coding functionality helps you analyze your data faster.

Now that we have a couple codes, let's try managing our codebook. Click and drag the [test1] code on top of the [test] code to make [test1] a "child" of [test] (the "parent"). Do the same with [test2]. This allows you to associate codes and organize them in a tree structure. Right-click on [test1] and click `Edit Description...`; this opens a popup where you can write more details about the code. The description is useful for defining what a given code means. Also from the right-click menu you can: change (parent) code colors, unparent a code, rename a code, or merge two codes. Let's try the last one: Right-click [test2] and merge it into [test1]. Note that [test1] will still exist in the codebook, and every segment that was coded as [test2] will now be coded as [test1].

There are also ways to compare separate codings by different users. Try clicking on the dropdown menu under "Coded Segments" in the right pane; Notice that there is a "Tutorial" user with an unchecked box. Click on "Tutorial" and notice that new coded segments show up in the document. Also notice that the coded segments are split vertically: This allows you to compare how two (or more) people coded the same document. Segments coded with different codes will be highlighted in red, to show where there are mismatches. Two people can code in the same project by sharing the same project file; coded segments will automatically be saved under their username.

As an aside: There is no built-in file / coding sharing mechanism for Open Ansho. Instead, you can simply share a project file. This can be done with file sharing systems like Dropbox, OneDrive, or Google Drive.

Finally, Note that under the File menu there is a `Merge Project...` option. If you and a collaborator ever work on a project separately, you can use to merge your work back together. This can be helpful if you are using a file sharing system (e.g., Dropbox) and there is important work in a conflicted version of the shared file.

Now let's talk about navigation using the codebook. One use of codes is to find relevant parts of the data. The codebook shows the number of coded segments in the current document, and the total number of coded segments across all documents. You can list all coded segments by selecting a code, either by clicking a coded segment in the document, or by selecting a code in the codebook. Note that you can search for coded segments in a document by pressing c (and Shift + c for backward search). When a code is selected, you can see the text of coded segments in the bottom of the right pane. Double-click on a coded segment to jump to that segment: This may take you to a different document.
